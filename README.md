# toybox

项目启动脚手架

##### 示例
[example](https://github.com/inoth/toybox/tree/v4/example/demo-wire)

---
##### go mod 拉取包
```shell
go get -u github.com/inoth/toybox@latest
```
##### 初始化工具  
```shell
go install github.com/inoth/toybox/cmd/toybox@latest
```
```shell
toybox new helloworld

cd helloworld
```
